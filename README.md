# Virtual-Skin-Care-recommender-

A deep learning-based system that analyzes facial images to detect skin type and acne severity, then recommends personalized skincare products.

🔍 Features
Classifies skin type (Dry, Normal, Oily) and acne level (Level 0–2) using EfficientNet-B0.

Recommends products based on a KNN similarity algorithm using user features.

Integrates a product dataset for real-time suggestions with price and brand info.

🧠 Tech Stack
Python, TensorFlow, Pandas, NumPy

EfficientNet-B0 for image classification

KNN for recommendation

📊 Datasets
Acne Images: 999

Skin Type Images: 1275

Product Info: Excel-based, labeled by concern
